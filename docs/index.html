Your agent’s page, corrected.

Ask a coding agent for a SaaS homepage and it builds the same one everyone gets. noslopdesign is two skills and a linter that mark up that page the way an editor marks up a draft, then send the agent back to fix it.

How a build runs

One request, six moves. The agent cannot call it done until the page has been looked at.

you  $noslop-frontend make a SaaS homepage for a bank reconciliation tool
agent size C3 · surface landing · locale ko+en · assets: product screenshots
agent brief is vague → noslop-uiux Design Read → direction locked in DESIGN.md
agent build: real screenshots, one accent, Pretendard + Plex Mono for figures
agent sloplint ./src → 2 reflex: NS-EYEBROW, NS-BORDER-SHADOW → fixed
agent browser 390 / 768 / 1440 → hero wraps badly at 390 → fixed, re-shot
done  checked: sloplint 0 blocking · 3 widths · keyboard pass · axe 0

  1. Size and route

    Copy fix or new surface; landing, app or dashboard; locale; density; which assets are real.

  2. Decide the direction

    noslop-uiux turns “make it look good” into one direction and writes it to DESIGN.md.

  3. Build with real material

    Product screenshots, real numbers, real copy. No gradient blobs standing in for a product.

  4. Lint the tells

    sloplint catches the static ones before a browser even opens.

  5. Look at it

    Three widths in a real browser. Screenshots are read, not just taken.

  6. Report the evidence

    What was checked and how, so “done” means something.

Three tiers of “no”

Not every rule is a wall. The floor never moves; reflexes need a written reason; finish is taste.

Floor never ships

  • NS-ZOOM viewport blocks zoom
  • NS-FOCUS-GONE outline removed, nothing in its place
  • NS-PLACEHOLDER filler copy and stand-in names
  • NS-EMOJI-UI emoji as icons

Reflex needs a reason

  • NS-PURPLE-GRADIENT
  • NS-INTER-ONLY
  • NS-BUZZWORD elevate, seamless, unleash
  • NS-VANITY-METRIC 10,000+ teams

/* noslop-allow NS-GRADIENT-TEXT: licensed wordmark */

Finish never blocks

  • NS-TEXT-WRAP headings without balance
  • NS-100VH use 100dvh
  • NS-TRANSITION-ALL
  • NS-EM-DASH too many dashes
$ node skills/noslop-frontend/scripts/sloplint.mjs ./index.html
[floor]  NS-ZOOM            index.html:2   Viewport blocks zoom.
[reflex] NS-PURPLE-GRADIENT index.html:4   Purple or indigo gradient.
[reflex] NS-BUZZWORD        index.html:5   Generated marketing verbs.
not ok - 1 file(s), 3 blocking, 0 advisory

Two skills, one front door

noslop-frontend

Builds, redesigns and fixes pages and app screens in your stack. Start here; it calls the other skill when the brief is vague.

build · redesign · polish · audit · critique · bolder · quieter · harden

noslop-uiux

Direction before code: intent discovery, Design Read, concept mockups, design systems, UX states, logos and favicons.

깔끔하게 · 모던하게 · 감성적으로 · 토스 느낌 · Linear처럼
