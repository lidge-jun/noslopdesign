처음 연결할 때 지난 3개월치 정산도 같이 맞춰 봐요. 이미 지나간 차이도 판매처 기준 기한 안이라면 문의할 수 있어요.

  1. 1

    판매처 연결

    판매자센터의 API 키를 넣거나 정산 엑셀 파일을 올려요. 비밀번호는 받지 않아요.

  2. 2

    매일 오전 6시 대조

    전날까지의 주문, 정산, 반품, 광고비 차감을 주문번호 기준으로 한 줄씩 맞춰요.

  3. 3

    근거와 문의 문구 준비

    차이 건마다 계산 근거 파일과 판매처 문의 문구를 만들어 둬요. 보내는 건 직접 확인한 뒤에 해요.

자주 묻는 질문

지원하는 판매처는 어디인가요?
지금은 스마트스토어, 쿠팡(로켓그로스 포함), 11번가를 지원해요. G마켓과 옥션은 엑셀 업로드로 먼저 쓸 수 있어요.
차이를 찾으면 셈이 대신 청구하나요?
아니요. 근거 파일과 문의 문구까지만 준비해요. 판매처에 보내는 건 판매자가 직접 확인하고 보내요.
세무사에게 자료를 넘길 수 있나요?
성장 요금제에서 월별 정산 대조표를 엑셀로 내려받을 수 있어요. 세무사를 팀원으로 초대해 열람만 허용할 수도 있어요.
무료 기간이 끝나면 자동 결제되나요?
시작할 때 카드를 받지 않아서 자동 결제는 없어요. 14일이 지나면 대조만 멈추고, 그동안 찾은 내역은 그대로 볼 수 있어요.
