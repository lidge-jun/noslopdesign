# 굽 커피 DESIGN.md

Reading this as: a neighborhood cafe landing page for Seongsu-dong locals and weekend visitors, built from the area's own material: red-brick shoe workshops, concrete floors, workshop job tickets.

- Background #eceeec (cool concrete), surface #e1e4e2, ink #1c1f1e, muted #535a57, line #c3c8c5
- One accent: brick #a3381f (CTA, today row, map route). Line 2 green #3d8b52 only on the map.
- Type: Pretendard Variable for Hangul (h1 700, line-height 1.3, keep-all); IBM Plex Mono for prices, hours and live status (tabular numbers).
- Layout: 5/7 asymmetric grid; ruled lists and tables instead of cards; real photography.
- Dials: VARIANCE 6, MOTION 3, density D3. Motion is one scroll reveal, disabled under reduced motion.
- Don'ts: cream or beige paper palette, icon tiles, eyebrow labels, gradient washes, italic serif hero.
- Content note: cafe name, address, prices and hours are sample content for a fictional shop.
