Capped at fifteen, on purpose

Past fifteen people, a team needs triage meetings, permission screens and a tracker that behaves like a database. Below it, everyone can read the whole list on a Monday morning and know who has what.

Punchlist is built for that size and stops there. No roles to configure, no workflow editor, no story points. Every decision in it assumes you know each other’s names.

Branches name themselves

Copy the branch name with ⌘⇧. and push. The pull request links itself, and merging it punches the issue.

Weeks that end on Friday

A cycle is one week. At 17:00 on Friday whatever is left rolls into the next one, and nobody holds a planning meeting about it.
