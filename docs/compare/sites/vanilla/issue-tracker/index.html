Features

Everything a small team needs. Nothing it has to maintain.

No custom field sprawl, no workflow builder, no admin. Sensible defaults that you can change in a minute.

⌘

Keyboard first

Create, assign, and close issues without touching the mouse. Every action has a shortcut and lives in the command menu.

↻

Two-week cycles

Unfinished work rolls over automatically. Scope changes are tracked, so planning stays honest.

◎

Triage inbox

Bug reports from Slack, email, and Sentry land in one queue. Accept, merge duplicates, or decline in a keystroke.

⑂

GitHub and GitLab sync

Mention PLT-412 in a branch and the issue moves to In progress. Merge the PR and it closes.

⚡

Instant everywhere

A local-first sync engine means views open in under 50 ms and changes appear for teammates in real time.

▦

Lightweight roadmap

Group issues into projects with a target date. See what's on track at a glance, no Gantt chart required.

    FAQ

    Questions, answered

    Can we import from Jira, GitHub Issues, or Linear?

    Yes. The importer brings over issues, comments, labels, and assignees. Most teams finish in under ten minutes.

    What happens when we grow past 5 people on Free?

    Nothing breaks. You'll be asked to upgrade before inviting a sixth member, and your existing data stays put.

    Does Kestrel work offline?

    Yes. The app keeps a local copy of your workspace, so you can read and edit issues offline. Changes sync when you reconnect.

    Where is our data stored?

    In encrypted Postgres databases in the EU or US, your choice. You can export everything as JSON or CSV at any time.
